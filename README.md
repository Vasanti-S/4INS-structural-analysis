# Structural Analysis of Insulin (4INS)

A computational structural biology project analyzing the insulin structure (PDB: 4INS) using Python.

## Project Overview

This project explores the three-dimensional structure of insulin and demonstrates how Python can be used to perform basic structural analysis of a protein.

The analysis includes:

- Downloading and inspecting a PDB structure
- Parsing protein structural data with Biopython
- Examining chains, residues, and atoms
- Calculating distances between atoms
- Identifying residues in the local structural environment of Tyr14
- Visualizing protein structure using py3Dmol
- Connecting structural information with protein-engineering concepts

## Tools & Libraries

- Python
- Biopython
- NumPy
- py3Dmol
- Jupyter Notebook

## Structure Analyzed

**Protein:** Insulin  
**PDB ID:** 4INS  
**Focus residue:** Tyr14 (TYR14)
